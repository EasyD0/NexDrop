这个初版功能描述如下:
1. 左侧栏
	- 是可收起的已连接的设备列表, 
	- 点击设备列表的条目可以进入与该设备的交互主界面
	- 设备列表的条目可以自由删除 （断开连接）、重命名
	- 列表底部是一个加号，用于增加设备
	- 还有一个设置按钮，进入设置界面

1.1 设置界面
	- 用于配置默认下载路径
	- 配置被其他设备看到的设备名称
	- 接收从已配对的设备发来的文件， 是否需要临时配对码弹窗验证

1.2 增加设备时的设备配对：
	- 点击 加号后，会自动扫描局域网可用设备（装了并开启这个软件的设备）
	- 选中要配对的设备，会生成一个配对码，并对那个设备进行配对请求，在被配对的设备上可以同意、拒绝 


2. 主界面有两个框：文件框用于文件传递, 文本框用于传输文本
	- 桌面端同时展示两个框
	- 移动端，通过左右滑动切换

3. 文件框
	- 暂时不实现拖放功能
	- 整个框是文件列表
	- 列表空白区域点击后将打开资源管理器进行文件选择, 选中的文件将以列表呈现
	- 每个文件条目右侧有移除按钮
	- 框下面有个三个按钮：
		清除：清除文件列表
		发送：发送文件

4. 文本框: 
	- 底部三个按钮：
		复制：将框里的文本复制到系统剪切板
		粘贴：将框里的文本清除，并将系统剪切板的内容粘贴到框里
		清除：清空框里的文本
		发送：开始发送

### 文件收发
发送方发送文件时：
	按下发送按钮后, 对应的 文件框 将变为显示一个圆形进度条, 中间是配对码，下方是一个 中断发送 按钮

接收方接收文件时：
	立即切换到 文件框, 将只显示一个圆形进度条, 中间是配对码
	如果需要临时配对码弹窗验证, 则下方呈现 接收、拒绝 按钮
	若无需验证，则下方只有一个取消按钮，并立即开始下载

### 文本收发
发送方发送文本时：按下发送按钮后
	对应的 文本框 将变为显示一个圆形进度条，中间是配对码，下方是中断按钮
	发送完成后，界面变回文本框

接收方接收文本时：
	立即切换到 文本框, 将只显示一个圆形进度条，中间是配对码（但无需验证）
	文本收发无需验证，下方只有一个取消按钮，并立即开始接收

### 冲突处理
多设备冲突时（被发送方正在 发送、接收），后来的发送方直接发送失败
